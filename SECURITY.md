# Security reporting

Report suspected vulnerabilities privately to Previn Kalisetty Appadu at [hi@previn.me](mailto:hi@previn.me). Include the plugin, WordPress, PHP and WooCommerce versions, the affected feature and reproducible steps. Redact keys, credentials, cookies, exports and customer information.

See the [plugin security design](wp-utility-suite/SECURITY.md) for trust boundaries and the [release validation](docs/RELEASE-VALIDATION.md) for known limitations. The 0.1 series is a staging prerelease.
